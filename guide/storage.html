DSLR STORAGE SETUP

촬영 사진 저장 경로 설정

digiCamControl에서 사진이 촬영되어도 RusticaStudio 앨범에 나타나지 않는다면, 두 프로그램의 저장 경로를 확인해 주세요.

중요: 두 경로는 역할이 다릅니다

RusticaStudio의 최종 저장 위치와 digiCamControl의 촬영 원본 수신 폴더를 같은 폴더로 지정하는 것이 아닙니다. digiCamControl은 RusticaStudio가 감시하는 DSLR_IMPORT 폴더에 저장해야 합니다.

사진이 저장되는 흐름

① digiCamControl 촬영
카메라에서 촬영한 사진을 DSLR_IMPORT 폴더에 저장합니다.

↓ RusticaStudio가 새 파일 감지 및 복사

② RusticaStudio 세션
설정에서 지정한 최종 저장 위치 아래의 날짜·세션 폴더에 사진을 보관합니다.

↓ 앨범에서 사진 선택

③ COPY 폴더
선택한 사진을 기존 COPY 처리 방식에 따라 복사합니다.

1. RusticaStudio 저장 위치 확인

관리자 설정에서 저장 위치를 확인합니다. 이 위치는 최종 촬영 세션과 COPY 폴더를 저장하는 기준입니다. 예를 들어 다운로드를 선택했다면 다운로드 아래에 세션 폴더가 생성됩니다.

이 설정을 변경해도 digiCamControl의 촬영 저장 경로가 자동으로 변경되는 것은 아닙니다.

2. digiCamControl 촬영 저장 경로 설정

digiCamControl에서 촬영 사진의 PC 저장 위치를 확인하고, 아래 RusticaStudio 전용 수신 폴더로 지정합니다. 카메라별 저장 옵션과 세션 설정에 따라 메뉴 위치가 다를 수 있으므로 실제 촬영 파일의 저장 위치를 기준으로 확인해 주세요.

기본 DSLR 원본 수신 폴더%USERPROFILE%\Downloads\RusticaStudio_DSLR_IMPORT

위 경로는 일반적인 기본 예시입니다. Windows 다운로드 폴더가 이동된 경우 실제 다운로드 경로를 확인해야 합니다. RusticaStudio가 사용하는 DSLR_IMPORT 경로와 정확히 일치해야 하며, 임의의 Google Drive·OneDrive 폴더를 대신 지정하지 마세요.

1
현재 저장 폴더 확인

digiCamControl에서 사진 한 장을 촬영하고 실제 JPG 파일이 저장되는 위치를 확인합니다.

2
DSLR_IMPORT로 변경

촬영 결과의 PC 저장 위치를 RusticaStudio 전용 수신 폴더로 설정합니다. 폴더가 없다면 생성한 뒤 지정합니다.

3
새 촬영으로 테스트

RusticaStudio에서 새 세션을 시작하고 사진 한 장을 촬영합니다. 수신 폴더에 파일이 생성되고 앨범에 표시되는지 확인합니다.

3. 앨범이 비어 있을 때

이번 설치에서 확인된 사례

digiCamControl은 Google 가상 드라이브에 사진을 저장하고, RusticaStudio는 다운로드 아래의 DSLR_IMPORT 폴더를 감시하고 있었습니다. 따라서 촬영은 되었지만 앨범으로 사진이 들어오지 않았습니다. 두 경로를 맞춘 뒤 새 촬영으로 확인해 주세요.

기존에 다른 폴더에 저장된 사진은 경로를 변경해도 현재 앨범에 자동으로 추가되지 않습니다. 기존 원본은 삭제하거나 이동하지 말고 보존한 상태에서 새 사진으로 테스트하세요.

LiveView가 나오지 않는 문제는 저장 경로와 별개입니다. 이 경우에는 digiCamControl WebServer 설정을 먼저 확인해 주세요.

✓ RusticaStudio의 최종 저장 위치를 확인했나요?

✓ 새 촬영 사진이 수신 폴더에 생성되나요?

✓ RusticaStudio 앨범에 새 사진이 표시되나요?
