02 CAMERA SOFTWARE

digiCamControl 설치

DSLR 카메라를 사용하려면 별도의 카메라 제어 프로그램이 필요합니다.

▣

공식 사이트에서 직접 설치

RusticaStudio 설치 파일에는 digiCamControl이 포함되어 있지 않습니다.

digiCamControl 공식 다운로드 ↗

현재 검증 환경: digiCamControl 2.1.7.0 · Nikon Z5. 다른 버전이나 카메라는 지원 여부를 먼저 확인해 주세요.

1
공식 다운로드 페이지 접속

공식 사이트에서 판매자가 안내한 검증 버전의 설치 파일을 선택합니다.

2
설치 경로 확인

현재 RusticaStudio는 아래 기본 설치 경로를 사용합니다. 설치 위치를 임의로 변경하지 않는 것을 권장합니다.

C:\Program Files (x86)\digiCamControl
3
시작 팝업이 계속 보이지 않도록 설정

digiCamControl의 Settings에서 Start minimized를 활성화해 주세요. 설정 후 digiCamControl을 완전히 종료하고 다시 실행합니다.

4
카메라 단독 연결 테스트

카메라를 USB로 연결하고 digiCamControl에서 카메라가 인식되며 LiveView가 정상적으로 표시되는지 확인합니다.

별도 소프트웨어 안내

RusticaStudio와 digiCamControl은 서로 다른 소프트웨어입니다. digiCamControl의 설치 및 이용에는 해당 소프트웨어의 라이선스와 이용 조건이 적용됩니다. RusticaStudio는 digiCamControl의 공식 제품이 아닙니다.

SAVE FOLDERDSLR_IMPORT

촬영 원본 수신 폴더%USERPROFILE%\Downloads\RusticaStudio_DSLR_IMPORT

Windows의 실제 다운로드 폴더를 기준으로 합니다. OneDrive 등의 폴더 이동 설정이 있는 경우 판매자와 실제 경로를 확인해 주세요.

LiveView 확인

여기까지 완료됐다면

digiCamControl 단독 LiveView와 WebServer 설정이 모두 완료된 상태입니다. 그다음 RusticaStudio에서 촬영 방식을 digiCamControl로 선택하고 연결을 진행해 주세요.

RusticaStudio 카메라 설정

RusticaStudio 관리자 설정에서 촬영 방식을 digiCamControl로 선택하고 저장합니다. digiCamControl 방식에서는 카메라 선택 드롭다운이 비어 있어도 DSLR 연결 자체의 이상을 의미하지 않습니다.

04 FIRST SESSION

첫 촬영 테스트

실제 사진 한 장을 촬영하고, 갤러리와 저장 위치까지 확인해 주세요.

1
시작하기

시작 화면에서 시작하기를 누르고 카메라의 LiveView가 정상적으로 표시되는지 확인합니다.

2
자동 타이머로 촬영

관리자가 설정한 촬영 간격에 따라 자동 촬영이 진행됩니다. 카메라 물리 셔터도 지원 환경에서 함께 사용할 수 있습니다.

3
촬영 결과 확인

실제 사진이 생성되면 플래시와 썸네일로 촬영 결과를 확인할 수 있습니다. 촬영 요청과 실제 사진 저장은 별개의 과정입니다.

4
촬영 종료

촬영을 마친 뒤 촬영 종료를 누릅니다. 앨범 보기가 활성화된 경우 사진 선택 화면으로 이동합니다.

물리 셔터와 리모컨

실제 카메라 물리 셔터 촬영은 검증됐지만, 모든 리모컨의 호환성이 확인된 것은 아닙니다. 리모컨은 사용 전 해당 카메라에서 별도로 테스트해 주세요.

사진 선택 및 저장

마음에 드는 사진을 원본 크기로 확인하고, 인화할 사진을 별표로 선택할 수 있습니다.

원본 세션에는 관리자 설정의 자동 삭제 시간이 적용될 수 있습니다. 선택 완료 후 생성되는 COPY 폴더는 RusticaStudio의 자동 삭제 대상에서 제외됩니다. 중요한 사진은 별도 백업을 권장하며, OneDrive 동기화도 정상 완료됐는지 확인해 주세요.

06 TROUBLESHOOTING

문제가 발생했나요?

자주 발생하는 문제부터 확인해 보세요. 해결되지 않으면 고객지원으로 문의해 주세요.

카메라가 인식되지 않아요.+
카메라 전원과 USB 케이블을 확인한 뒤 digiCamControl을 단독으로 실행해 보세요. 다른 카메라 제어 프로그램이 연결을 점유하고 있다면 종료한 후 다시 확인합니다. 카메라 모델의 호환성과 지원 기능도 확인해 주세요.
LiveView가 나오지 않아요.+
digiCamControl에서 LiveView가 보이더라도 RusticaStudio 연결용 WebServer가 꺼져 있을 수 있습니다. Settings → Webserver에서 Use web server를 체크하고, 포트 5513, Allow interaction via webserver 체크, Allow public access 해제를 확인한 뒤 digiCamControl을 완전히 종료하고 다시 실행해 주세요.
사진을 찍었는데 갤러리에 없어요.+
digiCamControl에서 실제 촬영 파일이 생성됐는지, 촬영 원본 수신 폴더가 올바른지 확인해 주세요. 전송 중인 파일은 쓰기가 완료된 뒤에 처리됩니다. 원본 파일을 임의로 이동하거나 삭제하지 말고 고객지원에 문의해 주세요.
저장한 사진을 찾을 수 없어요.+
RusticaStudio 관리자 설정의 저장 위치를 확인해 주세요. 매장명과 날짜·시간으로 만들어진 세션 폴더를 확인하고, 선택한 사진은 해당 세션의 COPY 폴더를 확인합니다. OneDrive를 사용한다면 동기화 상태도 별도로 확인해 주세요.
설치 또는 업데이트가 되지 않아요.+
RusticaStudio를 완전히 종료한 뒤 공식 릴리스 페이지에서 설치 파일을 다시 확인해 주세요. 보안 경고가 발생하면 파일의 배포처를 확인하고, 출처가 불분명한 파일은 실행하지 마세요. 해결되지 않으면 오류 화면을 고객지원에 전달해 주세요.
