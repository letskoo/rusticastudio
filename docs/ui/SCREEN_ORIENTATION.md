# Screen Orientation

RusticaStudio의 모니터 방향에 따른 화면 표시 정책을 정의한다.

이 문서는 화면 구성만 담당한다.

촬영 방식, 카메라 연결, LiveView 통신, 촬영 완료 처리,
세션 저장, 앨범 선택, COPY 등의 기존 기능 로직은 변경하지 않는다.

---

## 1. 목적

RusticaStudio는 가로 모니터와 세로 모니터를 모두 지원한다.

모니터 방향에 따라 화면 구성을 자동으로 변경하여
카메라를 가로 또는 세로 방향으로 설치했을 때
각 설치 환경에 적합한 화면을 제공한다.

기본 원칙:

- 가로 모니터에서는 기존 가로 화면 구성을 유지한다.
- 세로 모니터에서는 세로 화면에 적합한 구성을 사용한다.
- 화면 방향 변경은 UI 표시 방식만 변경한다.
- 촬영 및 저장 로직에는 영향을 주지 않는다.

---

## 2. 화면 방향 판별

화면 방향은 Windows에서 RusticaStudio가 표시되는 현재 화면의
가로/세로 상태를 기준으로 판별한다.

카메라의 물리적인 설치 방향을 감지하거나 판단하지 않는다.

기준:

- 화면 너비 >= 화면 높이 : 가로 모니터
- 화면 너비 < 화면 높이 : 세로 모니터

화면 방향은 별도의 카메라 모드가 아니다.

카메라 연결 방식과도 독립적이다.

다음 기능의 동작을 변경하지 않는다.

- webcam
- digiCamControl
- 자동 타이머 촬영
- 물리 셔터 촬영
- 세션
- DSLR Watcher
- 사진 저장
- 앨범 선택
- COPY

---

## 3. 가로 모니터

가로 모니터에서는 현재 RusticaStudio의 화면 구성을 유지한다.

기존 가로 UI를 기준 화면으로 사용한다.

적용 대상:

- 시작 화면
- 광고 화면
- 촬영 화면
- LiveView
- 앨범
- 관리자 화면

가로 화면 지원을 위해 기존 촬영 로직이나
화면 동작을 변경하지 않는다.

---

## 4. 세로 모니터

세로 모니터에서는 화면의 중앙 세로 영역을 기준으로
RusticaStudio UI를 표시한다.

가로 화면에서 사용하던 UI의 불필요한 좌우 영역을
세로 모니터에서 그대로 유지하지 않는다.

세로 화면에 필요한 주요 콘텐츠와 조작 요소가
화면 안에 들어오도록 배치한다.

---

## 5. 시작 화면

### 가로 모니터

현재 시작 화면 전체를 표시한다.

기존 화면 구성과 시작 버튼 위치를 유지한다.

### 세로 모니터

기존 시작 화면의 중앙 세로 영역을 기준으로 표시한다.

가로 화면의 좌우 여백은 표시 대상에서 제외한다.

다음 요소는 세로 화면에서도 사용할 수 있어야 한다.

- 시작 화면 주요 콘텐츠
- 시작하기 버튼
- 관리자 진입 버튼

시작하기 버튼의 기능은 변경하지 않는다.

---

## 6. 광고 화면

광고 화면도 시작 화면과 동일한 화면 방향 정책을 사용한다.

가로 모니터에서는 기존 화면을 유지한다.

세로 모니터에서는 중앙 세로 영역을 기준으로 표시한다.

광고 페이지의 로딩 및 페이지 전환 로직은 변경하지 않는다.

---

## 7. LiveView

LiveView는 이번 화면 방향 기능에서 가장 중요한 영역이다.

목표는 카메라 설치 방향과 모니터 방향을 맞췄을 때
LiveView가 화면을 최대한 가득 채우도록 하는 것이다.

### 가로 카메라 + 가로 모니터

가로 방향으로 설치된 카메라의 LiveView를
가로 모니터에 맞게 표시한다.

LiveView가 가로 화면을 최대한 채우도록 한다.

### 세로 카메라 + 세로 모니터

세로 방향으로 설치된 카메라의 LiveView를
세로 모니터에 맞게 표시한다.

LiveView가 세로 화면을 최대한 채우도록 한다.

### 공통 원칙

화면 구성 변경을 위해 다음 기능은 변경하지 않는다.

- 카메라 연결
- webcam 스트림
- digiCamControl LiveView 요청
- LiveView 시작/종료
- 촬영 명령
- 촬영 완료 처리

화면 방향 기능은 전달받은 LiveView를
어떻게 화면에 표시할지만 담당한다.

---

## 8. 촬영 UI

세로 모니터에서도 기존 촬영 기능을 모두 사용할 수 있어야 한다.

포함되는 요소:

- LiveView
- 촬영 프레임 Overlay
- 세션 타이머
- 마지막 촬영 이미지 Preview
- 촬영 종료 버튼
- 촬영 종료 확인창
- Capture Flash

세로 화면에서는 각 요소의 위치와 크기를
세로 화면에 맞게 조정할 수 있다.

기능과 이벤트 처리는 변경하지 않는다.

### 세로 LiveView UI 배치

- 세션 타이머는 우측 상단에 배치한다.
- 세션 타이머는 좌측 상단 아이콘과 높이를 맞춘다.
- 촬영 종료 버튼은 우측 하단에 배치한다.
- 촬영 종료 버튼은 좌측 하단 아이콘과 높이를 맞춘다.
- 마지막 촬영 이미지 Preview는 우측 하단에 배치한다.
- 촬영 종료 버튼과 Preview는 동일한 영역에 겹쳐 배치한다.

평상시에는 촬영 종료 버튼만 표시한다.

촬영 직후에는 Preview가 촬영 종료 버튼 위에
일시적으로 표시된다.

Preview가 사라지면 촬영 종료 버튼이 다시 보인다.

기존 레이어 순서와 Preview 표시 시간을 유지한다.

기존 요소의 크기와 디자인은 유지한다.

위치 변경은 세로 모니터에서만 적용한다.

가로 모니터의 기존 UI 위치는 변경하지 않는다.

---

## 9. 앨범

앨범은 시작 화면이나 LiveView와 다르게
좌우 영역을 단순히 잘라서 표시하지 않는다.

촬영된 사진 전체를 사용자가 확인하고 선택할 수 있어야 하기 때문이다.

### 가로 모니터

현재 Desktop Gallery 구성을 유지한다.

### 세로 모니터

모바일 화면에 가까운 세로 Gallery 구성을 사용한다.

사진 Grid의 열 수와 간격을 세로 화면에 맞게 조정한다.

다음 기능은 그대로 유지한다.

- 전체 사진 표시
- 사진 선택
- 선택 해제
- 선택 개수
- 선택만 보기
- 원본 보기
- 원본 보기에서 선택/해제
- 선택 제한시간
- 선택 완료

화면 방향에 따라 앨범 데이터 자체를 필터링하거나
삭제하지 않는다.

---

## 10. 관리자 화면

관리자 화면의 기능과 설정 항목은 변경하지 않는다.

세로 화면에서 필요한 경우 화면 크기에 맞게
배치와 크기만 조정한다.

설정값의 의미와 저장 방식은 변경하지 않는다.

---

## 11. Capture Flash

Capture Flash는 모니터 방향과 관계없이
현재 화면 전체를 덮어야 한다.

가로 화면과 세로 화면 모두 동일한 촬영 플래시 동작을 유지한다.

---

## 12. 책임 범위

Screen Orientation 기능은 다음만 담당한다.

- 화면 방향 판별
- 가로 UI 적용
- 세로 UI 적용
- 화면 요소의 위치 및 크기 조정
- LiveView 표시 영역 조정
- 세로 Gallery 레이아웃 적용

다음 기능은 담당하지 않는다.

- 카메라 제어
- 카메라 방향 감지
- 카메라 회전 제어
- 촬영 명령
- 촬영 간격
- 촬영 완료 판단
- DSLR 파일 감시
- 세션 생성
- 이미지 저장
- COPY
- 앨범 선택 데이터 관리

---

## 13. 기존 기능 보호 원칙

Screen Orientation 구현으로 인해
기존에 검증된 촬영 기능을 수정하지 않는다.

특히 다음 영역은 화면 방향 구현을 이유로 변경하지 않는다.

- Camera Manager
- Capture Manager
- digiCamControl Service
- LiveView Service의 통신 로직
- DSLR Watcher
- Session 저장 로직
- COPY 로직
- Album 선택 로직

필요한 변경은 UI 계층에 한정한다.

---

## 14. Source of Truth

화면 방향에 따른 UI 정책은 이 문서를 기준으로 한다.

LiveView 자체의 연결 및 통신 정책은
LIVE_VIEW 문서를 따른다.

앨범의 선택 및 완료 정책은
ALBUM 문서를 따른다.

화면 방향과 기존 기능 정책이 충돌할 경우
기존 기능 동작을 유지하고 화면 배치만 조정한다.
